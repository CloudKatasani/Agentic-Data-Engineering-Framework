# Deposit balances and average daily balance data product - demo data pack

Domain Pack `financial-services` · demo Jira project `FIN` · reference stack `Microsoft Fabric + Purview + Power BI`.

All content is synthetic and generated by `python -m adef demo-data` (seed 4242).

| Folder | Contents | Use it in the console |
|---|---|---|
| `jira/` | 11 issues as a Jira CSV export and a REST/JSON export | New run → Requirements → *Upload Jira export* |
| `source-metadata/` | Source catalog export (CSV) and source DDL | New run → Source metadata, or Jira & metadata page |
| `source-data/` | Synthetic rows per source table | Load into a sandbox to show the pipeline on data |
| `model/` | DDL (Snowflake, Databricks, BigQuery, T-SQL), DBML, Mermaid, PlantUML, JSON, dbt, ODCS, dictionary | Model & catalog studio (import) |
| `catalog/` | Collibra, Purview/Atlas, DataHub, Alation, glossary, Unity Catalog and Snowflake governance SQL | Show catalog hand-off |
| `lineage/` | OpenLineage events, column and table lineage CSV, Mermaid lineage diagram | Show lineage hand-off |
